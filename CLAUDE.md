## Product Reference

[BERMAN_INSTITUTE_SYSTEM_REFERENCE.md](BERMAN_INSTITUTE_SYSTEM_REFERENCE.md) is the source of truth for what Berman Institute is and how it should behave. Read it before designing or building any page, flow, or feature.

It covers:
- System overview and the professional lifecycle (Discover → Learn → Complete → Earn Credential → Join Network → Participate → Contribute → Research → Teach)
- Core product principles (the experience should feel like Berman Institute, not a generic LMS)
- Grand Rounds format
- Site and portal structure: Public website, My Campus, Faculty Portal, Research / Editorial Portal, Admin
- My Campus sections: Home, Learn, Research, Network, Profile
- User journeys: Short Course, Advanced Certificate, Graduate

When a design or implementation decision conflicts with this reference, follow the reference or flag the conflict.
